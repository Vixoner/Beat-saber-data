# Zależności rankingowe w Beat Saber: Analiza statystyk graczy
Badanie analizuje zależności między różnymi statystykami graczy a ich globalnym rankingiem w Beat Saber, popularnej grze rytmicznej VR. Poprzez analizę danych z 10 000 najlepszych graczy, projekt identyfikuje kluczowe wskaźniki wydajności, które najsilniej wpływają na pozycję gracza w globalnej tabeli wyników BeatLeader.
